# Lab 4 - ASP.NET Core MVC / Entity Framework

**Sinh viên:** Sơn Lê Thế  
**GitHub:** [@SonConTe17](https://github.com/SonConTe17)

## Nội dung
Project gồm hai ứng dụng mẫu:
- `DBFirstApp`: ứng dụng ASP.NET Core MVC theo hướng Database First.
- `MyWebApp`: ứng dụng ASP.NET Core MVC với Entity Framework và dữ liệu mẫu.

## Ghi chú
- Trong `DBFirstApp`, danh sách chọn ngành hiển thị `MajorName` thay vì `MajorId`.
- Kiểm tra chuỗi kết nối trong `appsettings.json` trước khi chạy ứng dụng.
- Mở `Lab4.sln` bằng Visual Studio để làm việc với solution.
